# NEMATI STOR | نعمتی استور

فروشگاه آنلاین سه‌زبانه (دری، پشتو، انگلیسی) ساخته‌شده با Next.js، TypeScript، Tailwind CSS و PostgreSQL (از طریق Prisma).

⚠️ **مهم و صادقانه بگویم:** این پروژه یک اسکلت واقعی و قابل اجراست — نه Mockup — و تمام دکمه‌ها و صفحاتی که در ادامه گفته می‌شود واقعاً کار می‌کنند. اما محیطی که من (Claude) در آن کد می‌نویسم به اینترنت و به یک دیتابیس واقعی دسترسی ندارد، بنابراین نتوانستم `npm install` را اجرا کنم یا پروژه را زنده تست کنم. باید مراحل زیر را خودتان روی کامپیوتر یا سرور اجرا کنید. بخش‌هایی مثل «مدیریت سفارش‌های آنلاین با پرداخت» ساخته نشده چون شما فروش را از طریق واتساپ خواستید، نه درگاه پرداخت.

## 🚀 مسیر ساده — فقط با موبایل و مرورگر (بدون نصب چیزی، بدون ترمینال)

با این روش، ساخت دیتابیس و اجرای سایت به‌صورت خودکار حین Deploy انجام می‌شود.

**قدم ۱ — ساخت دیتابیس رایگان (Neon)**
1. با مرورگر موبایل بروید به **neon.com** → ثبت‌نام رایگان.
2. یک پروژه جدید بسازید.
3. در صفحه پروژه، روی «Connection String» بزنید و آن را کپی کنید (شبیه `postgresql://...`).

**قدم ۲ — بالا بردن کد در GitHub (بدون Git، فقط آپلود)**
1. بروید به **github.com** → ثبت‌نام رایگان → «New repository» بسازید (مثلاً به نام `nemati-store`).
2. داخل همان صفحه ریپو، روی «Add file → Upload files» بزنید.
3. فایل zip پروژه را باز کنید (روی موبایل با اپ فایل‌منیجر Extract/Unzip کنید) و همه‌ی فایل‌ها و پوشه‌ها را انتخاب و آپلود کنید. سپس «Commit changes» بزنید.

**قدم ۳ — Deploy در Vercel**
1. بروید به **vercel.com** → با حساب GitHub وارد شوید.
2. «Add New → Project» → همان ریپوی `nemati-store` را انتخاب کنید.
3. در بخش «Environment Variables» این مقادیر را وارد کنید:
   - `DATABASE_URL` → همان Connection String از Neon
   - `NEXTAUTH_SECRET` → هر رشته‌ی تصادفی طولانی (مثلاً چند کلمه و عدد به هم چسبیده)
   - `NEXTAUTH_URL` → بعد از اولین Deploy، آدرسی که Vercel می‌دهد (مثل `https://nemati-store.vercel.app`) را این‌جا بگذارید و یک‌بار دیگر Redeploy کنید
   - `SUPER_ADMIN_EMAIL` → ایمیلی که می‌خواهید با آن وارد پنل شوید
   - `SUPER_ADMIN_PASSWORD` → رمز عبور دلخواه برای پنل مدیریت
4. روی «Deploy» بزنید و چند دقیقه صبر کنید.

همین! ساخت جدول‌های دیتابیس و ساخت اولین Super Admin به‌صورت **خودکار** حین Build انجام می‌شود — نیازی به اجرای هیچ دستوری نیست.

بعد از Deploy، سایت شما زنده است و از مسیر `/fa/admin/login` با همان ایمیل و رمز عبوری که در `SUPER_ADMIN_PASSWORD` گذاشتید وارد پنل می‌شوید.

**برای تغییر رمز عبور پنل در آینده:** فقط مقدار `SUPER_ADMIN_PASSWORD` را در تنظیمات Vercel عوض کنید و یک‌بار «Redeploy» بزنید — رمز جدید خودکار جای رمز قدیمی می‌نشیند.

⚠️ محدودیت این روش: عکس‌هایی که از پنل آپلود می‌کنید روی Vercel دائمی نیستند (بخش ۶ زیر را ببینید) — برای شروع و تست کامل مشکلی نیست، اما پیش از فروش واقعی بهتر است Cloudinary وصل شود.

## ۲. روش نصب (فقط اگر کامپیوتر دارید و می‌خواهید Local کار کنید — با موبایل بخش بالا را دنبال کنید)

1. Node.js نسخه ۱۸ یا بالاتر را نصب کنید.
2. یک دیتابیس PostgreSQL بسازید (محلی یا ابری - بخش ۴).
3. در پوشه پروژه:
   ```bash
   npm install
   cp .env.example .env
   ```
4. فایل `.env` را باز کنید و مقادیر واقعی (`DATABASE_URL`, `NEXTAUTH_SECRET`, ...) را جایگزین کنید.

## ۳. اجرای Local

```bash
npm run db:push      # ساخت جدول‌ها در دیتابیس بر اساس schema.prisma
npm run db:seed       # ساخت اولین Super Admin و دسته‌بندی‌های پایه
npm run dev
```
سایت روی `http://localhost:3000` باز می‌شود (به‌صورت خودکار به `/fa` منتقل می‌شوید).

(نکته: دستور `npm run build` این دو کار را خودش هم انجام می‌دهد — به همین دلیل در Deploy روی Vercel نیازی به این دستورات جدا نیست.)

## ۴. اتصال Database

گزینه‌های ساده برای PostgreSQL رایگان/ارزان:
- **Neon** (neon.tech) — رایگان، سریع، مخصوص Next.js
- **Supabase** (supabase.com) — رایگان، همراه با Storage برای عکس‌ها
- **Railway** (railway.app)

بعد از ساخت دیتابیس، رشته اتصال (Connection String) را در `DATABASE_URL` داخل `.env` قرار دهید، سپس:
```bash
npm run db:push
npm run db:seed
```

## ۵. ساخت اولین Super Admin

مقدار `SUPER_ADMIN_EMAIL` و `SUPER_ADMIN_PASSWORD` را در `.env` تغییر دهید، سپس:
```bash
npm run db:seed
```
این دستور یک Super Admin با آن ایمیل و رمز عبور (به‌صورت Hash شده) می‌سازد. با همین اطلاعات از مسیر `/fa/admin/login` وارد پنل شوید. **بلافاصله بعد از اولین ورود، رمز عبور را از طریق ساخت یک Admin جدید و حذف این حساب، یا تغییر مستقیم در دیتابیس، تغییر دهید.**

## ۶. روش Deploy

ساده‌ترین راه: **Vercel** (سازنده‌ی Next.js)
1. پروژه را در یک ریپوی GitHub/GitLab آپلود کنید.
2. در vercel.com پروژه را Import کنید.
3. متغیرهای محیطی (`DATABASE_URL`, `NEXTAUTH_SECRET`, `NEXTAUTH_URL`, `SUPER_ADMIN_EMAIL`, `SUPER_ADMIN_PASSWORD`) را در تنظیمات Vercel وارد کنید.
4. Deploy بزنید.
5. یک‌بار از طریق ترمینال به دیتابیس Production متصل شوید و `npx prisma db push` و `npm run db:seed` را اجرا کنید (یا این دو را به‌صورت یک‌باره در مرحله Build اجرا کنید).

⚠️ **نکته مهم درباره عکس‌ها:** روی Vercel فایل‌سیستم دائمی نیست، یعنی عکس‌هایی که از پنل آپلود می‌کنید بعد از مدتی پاک می‌شوند. برای Production واقعی باید آپلود عکس را به یک سرویس ابری مثل **Cloudinary** یا **Supabase Storage** وصل کنید (فایل `src/app/api/upload/route.ts` باید برای این تغییر کند). اگر بخواهید، در یک مرحله بعدی این اتصال را برایتان می‌سازم.
